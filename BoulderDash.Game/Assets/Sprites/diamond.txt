# Boulder Dash — Sprite: Diamond (8 Frames, 16x16)
# Ein Zeichen pro Pixel, Werte sind Indizes in die 8-Farben-Palette (siehe Palette.Expand):
# . = Farbe 0 (Hintergrund), : = Farbe 1, x = Farbe 2, # = Farbe 3
# , = Schatten von 0,   ; = Schatten von 1, + = Schatten von 2, % = Schatten von 3
# Innerhalb der [Frame]-Abschnitte sind keine Kommentarzeilen möglich,
# da Pixelzeilen mit '#' beginnen dürfen.
# Im Code: Element.Jewel.
# Die Facettenkanten stehen fest (oben hell : ;, unten dunkel x +) und geben dem Stein seine Form.
# Durch das Innere läuft das Funkeln als Tonwelle (: : ; x + + x ;), die pro Frame eine Zeile
# weiter wandert — dieselbe Idee wie im Original, nur mit acht statt vier Stufen und daher
# als weicher Lichtreflex statt als harter Farbwechsel.
